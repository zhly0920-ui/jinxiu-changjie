# 凤舞九州：锦绣长街

古风模拟经营游戏 v0.22 试玩。

[打开游戏，手机竖屏试玩](https://zhly0920-ui.github.io/jinxiu-changjie/?v=0.22)

从一针一线起家，首轮正式交付5件绣帕后，即可用200两开茶铺；绣坊继续升级，两店交替经营。

身世开篇使用原创古风纯音乐《凤阙雨夜》，进入经营切回《针线与烟火》。重看、暂停和返回均随场景切换。

本轮整理卷轴留白、弹窗标题位置、全部教学小手的指尖与实际操作位置、商街状态标签与灯市说明。含30款绣作、落针动画、圈圈指引与开铺故事。
